# P.808 Short-Batch Dereverb Listening

This is an independent listening entry. It is not linked from the older
ACE + AIR pages.

Each batch contains 15 samples. The last batch contains 13 samples. A listener
can submit one completed batch and return later with the same listener ID to
continue. Submitted sample IDs are stored locally and are not selected again.

Each sample contains a visible reference and ten anonymous versions: eight
model outputs, one hidden reference, and one unprocessed input. The ten scores
must be distinct so the versions form an unambiguous ranking. Scores use a
0.0–10.0 scale with 0.1 increments.

The page follows the short-task, randomized-selection, listener-metadata and
independent-submission organization described by ITU-T P.808. The distinct
score requirement and 10-point ranking scale are project-specific extensions,
not a claim of full conformance with every P.808 procedure.

Reference: [ITU-T P.808](https://www.itu.int/rec/T-REC-P.808/en).
